# Fiber Tree Calculator (Next.js)

This project was migrated from a vanilla JS/HTML version to a modern Next.js 15+ application.

## How to upload to GitHub

1.  **Create a new repository** on GitHub (do not initialize with README or License).
2.  **Copy the repository URL** (e.g., `https://github.com/yourusername/fiber-tree-next.git`).
3.  **Open a terminal** in this folder (`c:\Users\USER\Documents\antigrafity\fiber-tree-next`).
4.  **Run these commands**:

```bash
git remote add origin YOUR_REPOSITORY_URL
git branch -M main
git push -u origin main
```

## How to run locally

```bash
npm install
npm run dev
```
